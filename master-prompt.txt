# MASTER IMPLEMENTATION PROMPT — SPECTRA

## Project

Build the complete production-oriented master's project:

# **SPECTRA**

### **Hypothesis-Driven Multimodal Enterprise Investigation Agent**

Formal description:

> SPECTRA is an agentic enterprise investigation platform that autonomously investigates questions across documents, images, audio, videos, structured databases, and configurable external sources. It resolves entities across modalities, generates and tests competing hypotheses, retrieves supporting and disconfirming evidence, detects contradictions, reconstructs timelines, maintains an evidence graph, verifies conclusions, exposes provenance, and links discovered entities to corresponding enterprise application records.

The system must be fully runnable on a single **RTX 4090 24 GB VRAM** development machine.

The architecture must be designed so that the same system can later scale to **TBs of documents/images/video and millions or billions of database records** without requiring a fundamental rewrite.

```text

   ↓

   ↓
```

```text

            ↓
      Query Understanding
            ↓
       SPECTRA BRAIN
            ↓
      Plan / Hypotheses
            ↓
```
