Wiki: auth-service

Document DOC5504 | Wiki: auth-service | version 1 (current)

Overview

auth-service issues and validates session tokens for every customer-facing surface. It stores sessions in session-db.

Callers

payment-gateway calls token validation on the authorisation path and blocks on the answer, so authentication latency is payment latency.

Ownership

Owner: Marcus Halvorsen. Escalation: Amara Novak.

Known failure modes

Token validation latency above two seconds exhausts the payment-gateway connection pool. See INC9344.
