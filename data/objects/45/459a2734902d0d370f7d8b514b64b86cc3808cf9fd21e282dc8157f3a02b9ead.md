# ADR 0007: cache the token revocation list

_Document DOC3215 | ADR 0007: cache the token revocation list | version 1 (current)_

## Status

Accepted.

## Context

Release 2.14.0 of auth-service added a synchronous revocation-list lookup per token validation. Under load this contends on session-db and pushes p99 past eight seconds, which is what caused INC9344.

## Decision

Cache the revocation list in-process with a 30 second TTL and refresh it asynchronously.

## Consequences

A revoked token may be honoured for up to 30 seconds. The security review accepted that trade-off explicitly.
